## 一、预测成本统计

| 指标 | 数值 |
|------|------|
| 预测周期 | {report_period_start} 至 {report_period_end} |
| 预测总用电量 (MWh) | {total_load_mwh} |
| 预测市场参考电价 (元/MWh) | {avg_price} |
| 预测市场总电费 (元) | {total_cost} |

**计算逻辑**：
- 总用电量 = 客户历史日用电曲线 × 报告期天数
- 参考电价 = QUANT Agent LSTM 24点逐时预测的加权均价
- 总电费 = 总用电量 × 参考电价

## 二、成本分析

### 「分日分析」

**高成本风险预警**：
- 逐日计算日电费 = 日用电量 × 日预测均价
- 取 argmax 识别周期内电费最高日
- 标注该日为"重点用能管控风险日"
- 输出格式: "预测数据显示，您的用电成本高峰将出现在 X 月 X 日，届时日电费将达到 XXX 元，主要因其全日电价预测均值 XXX 元/MWh 为周期最高"

**成本波动主因**：
- 计算日用电量方差 vs 日电价方差
- 若电价方差 > 电量方差：主因是电价波动
- 输出格式: "预测期内，您的日均用电量相对平稳，但日电价水平波动显著（最高与最低日相差约 X%）。这表明，未来成本波动的首要驱动因素是预测电价的日间波动，而非用电量的变化"

### 「分时分析」

**"量价错配"风险诊断**：
- 加载省份 TOU 时段定义（尖峰/高峰/平段/低谷/深谷）
- 计算尖峰时段用电量占比 vs 尖峰时段电费占比
- 若电费占比 > 电量占比：存在"量价错配"
- 输出格式: "结合该省典型的5段分时电价结构分析，您的预测用电曲线与预测电价峰谷结构高度重合。在预测的尖峰电价时段，您将消耗 X% 的电量，但承担了 X% 的电费，存在显著的'高价高用'结构性问题"

**谷段利用潜力评估**：
- 计算深谷/低谷时段用电量占比
- 若占比偏低（<30%）：存在优化空间
- 输出格式: "在预测电价最低的深谷时段，您的用电量占比仅为 X%，未能充分利用低价电力，这是未来降低平均购电成本的主要优化方向"

### 「实时量价分析」

**极端高价损失点识别**：
- 逐小时扫描: hourly_cost[t] = load[t] × price[t]
- 取 argmax 定位最大单一小时损失点
- 输出格式: "预测显示，X 月 X 日 XX:00 将出现周期内最高电价 XXX 元/MWh，而您在该时点的预测负荷高达 XXX MWh，若不进行干预，该小时将产生 XXX 元的高额电费，是最大的单一成本侵蚀点"

**重复性高价窗口检测**：
- 滑动窗口检测连续高价时段（threshold = 90th percentile）
- 输出格式: "在 X 月 X 日至 X 日的晚间 XX:00-XX:00，预测电价将持续超过 XXX 元/MWh，而您的预测负荷仍将维持在高位（>XXX MWh）。这构成了一个连续、可预测的高成本风险窗口，需提前制定规避策略"

## 三、假设性分析及用电计划

我们为您假设贵企业在生产或其他用电属性中，包含一定可调负荷量或可能存在储能设备，提供未来用电建议，具体场景如下：

### 场景一：基础柔性调控（可调负荷 5%）

**负荷压降策略**：在每日预测电价最高的尖峰时段（10:00-12:00，19:00-21:00），削减最高5%的非生产关键负荷（如办公空调、部分照明、辅助通风）的功率。

**计算逻辑**：load_new[t] = load[t] × 0.95 (if t in peak_periods)，cost_new = Σ(load_new[t] × price[t])

- 预测总电费 (元): {s1_cost}
- 电费环比下降 (元): {s1_saving}
- 降本率 (%): {s1_pct}

### 场景二：生产工序优化（可调负荷 10%）+ 中小型储能套利

**负荷压降策略**：将一条可中断的预处理产线（约占总负荷10%）从每日午间尖峰时段（10:00-12:00）转移至凌晨深谷时段（02:00-06:00）运行。

**储能策略**：配置一套 1MW/2MWh 的工商业储能系统。谷段充电，在午、晚尖峰时段各放电1小时，实现"低储高发"。

- 预测总电费 (元): {s2_cost}
- 电费环比下降 (元): {s2_saving}
- 降本率 (%): {s2_pct}

### 场景三：深度调度与储能（可调负荷 15%）+ 大型储能

**负荷压降策略**：重组生产班次，将高耗能工序（约占总负荷15%）全部调整至夜间深谷时段运行。

**储能策略**：配置一套 2MW/4MWh 的储能系统。执行"两充两放"策略，在谷段充电，覆盖午、晚双尖峰，最大化套利。

- 预测总电费 (元): {s3_cost}
- 电费环比下降 (元): {s3_saving}
- 降本率 (%): {s3_pct}

## 用电计划

### 多用电

- **核心时段**：每日 00:00-08:00（深谷/谷段）
- **行动建议**：安排高耗电、可中断的生产工序（如原料处理、电加热、恒温车间）在此时段满负荷运行。若配置储能，应在此时段完成充电。

### 少用电

- **核心时段**：每日 10:00-12:00、19:00-21:00（尖峰时段）
- **行动建议**：在此时段降低非关键负荷用电，避免开启非必要的高耗能设备。对必须连续运行的生产线，提前评估是否可通过班次调整规避此窗口。
